# 경계구역 | BOUNDARY AREA

경계구역 공식 홈페이지 프로젝트입니다.

## 실행
- `index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행하세요.
- 배포할 때는 프로젝트 폴더 안의 파일과 `assets` 폴더를 함께 업로드하세요.

## 공식 사운드트랙
- `assets/music/boundary-zone-ost.mp3`에 경계구역 오리지널 시네마틱 OST가 포함되어 있습니다.
- 브라우저 자동재생 제한을 고려해 방문자가 오른쪽 아래 재생 버튼을 눌렀을 때 재생됩니다.
- 플레이리스트 버튼에서 현재 수록곡을 확인하고 다시 재생할 수 있습니다.

## 주요 파일
- `index.html`: 페이지 구조
- `style.css`: 디자인 및 반응형 스타일
- `script.js`: 캐릭터 팝업, 갤러리, 음악 플레이어 동작
- `assets/`: 로고, 캐릭터, 세계관, 활동 사진, 음악 파일
